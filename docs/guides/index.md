# Guides

Use these guides to complete a Context Guard task. Start with safe rollout;
open measurement only after normal policy and compact-output use is understood.

- [Roll out safely](safe-rollout.md) — observe, review, warn, and enforce.
- [Compact command output](compact-output.md) — run bounded commands and tests.
- [Run the repository examples](examples.md) — reproduce stored fixture output.
- [Inspect evidence](inspect-evidence.md) — retrieve artifacts and fragments.
- [Advanced measurement](measurement.md) — distinguish fixture, single-pair,
  and repeated evidence.

For exact commands, defaults, schemas, and files, use
[Reference](../reference/index.md).
